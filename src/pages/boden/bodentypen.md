# Bodentypen der Welt

## Klassifikationssysteme

Es gibt verschiedene internationale Systeme zur Bodenklass

ifikation:

**1. World Reference Base (WRB)**
- Internationale Standard (FAO/UNESCO)
- 32 Hauptbodengruppen (Reference Soil Groups)
- Aktuell: WRB 2022

**2. Soil Taxonomy (USDA)**
- US-amerikanisches System
- 12 Ordnungen (Orders)

**3. Deutsche Systematik**
- Bodenkundliche Kartieranleitung (KA5)
- Abteilungen, Klassen, Typen

## Hauptbodentypen nach Klimazonen

### Polare und Subpolare Böden

#### Cryosol (Permafrostboden)

**Charakteristik:**
- **Dauerfrost** (Permafrost) in <100 cm Tiefe
- Active Layer (Auftauschicht) im Sommer
- Geringe biologische Aktivität

**Verbreitung:**
- Arktis, Antarktis, Hochgebirge
- 24% der Nordhemisphäre-Landfläche

**Eigenschaften:**
- Wenig entwickelt
- Geringe Mächtigkeit
- Kryoturbation (Frostdynamik)

**Aktuelle Relevanz:**
- Permafrost-Tauen → Methan-Emission
- Klimawandel-Hotspot

### Boreale Zone

#### Podsol

**Charakteristik:**
- **Bleichung** (Asch-Horizont, E-Horizont)
- **Verlagerung** von Fe, Al, Humus
- **Saure Humusauflage** (Rohhumus)

**Entstehung:**
- Saurer Regen, Nadelstreu
- Chelat-Komplexe lösen Fe/Al
- Podsolierung (Verlagerungsprozess)

**Profil:**
```
O - Rohhumus (sauer)
E - Bleichhorizont (grau, ausgewaschen)
Bs - Anreicherungshorizont (braun, Fe/Al)
C - Ausgangsgestein
```

**Verbreitung:**
- Boreale Nadelwälder (Taiga)
- Skandinavien, Kanada, Russland

**Eigenschaften:**
- Sehr sauer (pH <5)
- Nährstoffarm
- Geringe Fruchtbarkeit

### Feuchte Mittelbreiten

#### Braunerde (Cambisol)

**Charakteristik:**
- **Brauner B-Horizont** (Verbraunung)
- Mäßig entwickelt
- Gute Durchwurzelung

**Entstehung:**
- Verwitterung in gemäßigtem Klima
- Verbraunung durch Eisenoxide
- Geringe Verlagerung

**Profil:**
```
Ah - Humushorizont (dunkel)
Bv - Verwitterungshorizont (braun)
C - Ausgangsgestein
```

**Verbreitung:**
- Mitteleuropa (häufigster Bodentyp!)
- Laubwälder, Ackerland

**Eigenschaften:**
- Mittlere Fruchtbarkeit
- pH 5-7
- Gute Durchwurzelung

#### Parabraunerde (Luvisol)

**Charakteristik:**
- **Tonverlagerung** (Lessivierung)
- Eluvial-Horizont (Tonabreicherung)
- Illuvial-Horizont (Tonanreicherung)

**Entstehung:**
- Aus Braunerde bei Tonverlagerung
- Mechanischer Transport von Tonpartikeln
- Typisch für Löss-Böden

**Profil:**
```
Ah - Humushorizont
Al - Eluvialhorizont (tonarm, heller)
Bt - Tonanreicherungshorizont (tonreich)
C - Ausgangsgestein (oft Löss)
```

**Verbreitung:**
- Lössgebiete Mitteleuropas
- Börden (sehr fruchtbar!)

**Eigenschaften:**
- **Sehr fruchtbar**
- Gute Wasserspeicherung
- Intensive Ackernutzung

#### Schwarzerde (Chernozem)

**Charakteristik:**
- **Sehr dunkler**, **humusreicher** A-Horizont (bis 1 m!)
- Kalkakkumulation im Unterboden
- Beste Ackerböden der Welt

**Entstehung:**
- Steppenvegetation (Gräser)
- Hohe Humusakkumulation
- Semiarides Klima

**Profil:**
```
Ah - Humusakkumulation (schwarz, 50-100 cm!)
Ck - Kalkhorizont
C - Löss
```

**Verbreitung:**
- Ukraine, Russland ("Schwarzerde-Gürtel")
- Great Plains (USA)
- Argentinien (Pampas)

**Eigenschaften:**
- **Höchste Fruchtbarkeit**
- Humusgehalt: 5-15%
- pH neutral (7)
- "Kornkammer" der Welt

### Trockene Mittelbreiten und Subtropen

#### Kastanozem (Kastanienfarbiger Boden)

**Charakteristik:**
- Dunkler A-Horizont (weniger als Schwarzerde)
- Kalkakkumulation
- Semiarid

**Verbreitung:**
- Trockenere Steppen (< Schwarzerde)
- Kasachstan, Mongolei

**Eigenschaften:**
- Fruchtbar (mit Bewässerung)
- Humusgehalt: 3-5%

#### Solonchak (Salzboden)

**Charakteristik:**
- **Salzakkumulation** an Oberfläche
- Weiße Salzkrusten
- Vegetationsarm

**Entstehung:**
- Hohe Verdunstung > Niederschlag
- Salzwasser-Grundwasser
- Bewässerung ohne Drainage

**Verbreitung:**
- Aride Regionen
- Mesopotamien, Zentralasien
- Problem: Versalzung von Ackerland!

**Eigenschaften:**
- **Unfruchtbar**
- pH >8
- Entsalzung sehr aufwendig

### Mediterrane Subtropen

#### Terra Rossa

**Charakteristik:**
- **Rote Farbe** (Eisenoxide)
- Entstehung aus Kalkstein
- Geringe Mächtigkeit

**Entstehung:**
- Verwitterung von Kalkstein
- CaCO₃ gelöst → Fe/Al-Oxide bleiben
- Rubefizierung (Rotfärbung)

**Verbreitung:**
- Mittelmeerraum
- Karstgebiete

**Eigenschaften:**
- Mittlere Fruchtbarkeit
- Oliven, Wein, Getreide
- Erosionsgefährdet

### Feuchte Tropen

#### Ferralsol (Laterit)

**Charakteristik:**
- **Tiefgründig** verwittert (>10 m!)
- **Rot** (Eisenoxide)
- **Sehr nährstoffarm**

**Entstehung:**
- Intensive tropische Verwitterung (Ferralitisierung)
- SiO₂ ausgewaschen
- Fe/Al-Oxide akkumuliert

**Profil:**
```
Ah - Dünner Humushorizont
Bo - Oxidhorizont (rot, mächtig)
C - Stark verwittert
```

**Verbreitung:**
- Tropische Regenwälder
- Amazonien, Kongo, Südostasien

**Eigenschaften:**
- **Paradox:** Üppiger Wald auf nährstoffarmen Böden
- Nährstoffe in **Biomasse** gespeichert!
- Nach Rodung schnell unfruchtbar
- pH 4-5 (sauer)

**Problem:**
- Shifting Cultivation funktioniert
- Dauerhafte Nutzung problematisch
- Erosion nach Entwaldung

#### Acrisol

**Charakteristik:**
- Tonverlagerung
- Sauer (pH <5)
- Mäßig verwittert

**Verbreitung:**
- Feuchte Tropen/Subtropen
- Übergang Ferralsol → Gemäßigte

**Eigenschaften:**
- Fruchtbarer als Ferralsol
- Aber: sauer, Kalkung nötig

### Hydromorph geprägte Böden

#### Gley

**Charakteristik:**
- **Grundwassereinfluss**
- **Reduktion** (Sauerstoffmangel)
- Rostflecken und Bleichzonen

**Profil:**
```
Go - Oxidhorizont (braun, Rostflecken)
Gr - Reduktionshorizont (grau/blau)
```

**Verbreitung:**
- Flussauen, Senken
- Grundwassernahe Standorte

**Eigenschaften:**
- Für Ackerbau oft zu nass
- Grünland, Feuchtwiesen

#### Pseudogley

**Charakteristik:**
- **Staunässe** (nicht Grundwasser!)
- Wechsel nass/trocken
- Stauhorizont (Ton, undurchlässig)

**Profil:**
```
Sw - Stauwasserhorizont (gefleckt)
Sd - Staukörper (Ton, dicht)
```

**Verbreitung:**
- Mitteleuropa auf Tonschichten

**Eigenschaften:**
- Schwierig zu bewirtschaften
- Drainage möglich

#### Histosol (Moorböden)

**Charakteristik:**
- **Organischer Boden** (>30 cm Torf)
- Geringe Zersetzung (Sauerstoffmangel)
- Sehr hoher C-Speicher

**Typen:**
- **Hochmoor:** Regenwasser, sauer, Torfmoos
- **Niedermoor:** Grundwasser, neutral, Seggen/Schilf

**Verbreitung:**
- Boreale Zone (häufig)
- Mitteleuropa (selten geworden, entwässert)

**Eigenschaften:**
- **Kohlenstoffspeicher** (wichtig!)
- Entwässerung → CO₂-Emission
- Landwirtschaft möglich (aber Abbau)

### Anthropogene Böden

#### Anthrosol

**Charakteristik:**
- **Vom Menschen geschaffen/stark verändert**
- Tiefgründige Umgestaltung

**Beispiele:**
- **Terra Preta** (Amazonien): Holzkohle-Böden, sehr fruchtbar
- **Plaggenesch** (Nordwestdeutschland): Aufgetragene Böden
- **Hortisol:** Gartenbau-Böden
- **Technosol:** Halden, Aufschüttungen

## Bodendegradation weltweit

**Gefährdete Böden:**
- **Erosion:** 24 Mrd. t fruchtbarer Boden/Jahr verloren
- **Versalzung:** 20% der bewässerten Flächen
- **Verdichtung:** Intensivlandwirtschaft
- **Versiegelung:** Urbanisierung (Deutschland: 54 ha/Tag)
- **Kontamination:** Schwermetalle, Pestizide

**Bodenschutz:**
- Sustainable Soil Management
- EU Soil Strategy 2030
- Regenerative Agriculture
